# Renace Contigo - Plataforma Digital

Este proyecto ha sido construido **desde cero**, escribiendo el código línea por línea para asegurar que sea ligero, rápido y totalmente personalizado para la misión de "Renace Contigo".

## ¿Qué ocupamos para hacerla (y mantenerla)?

Para trabajar en esta página web, no necesitas programas costosos ni computadoras potentes. Solo necesitas dos herramientas básicas que ya tienes o son gratuitas:

1.  **Un Editor de Código (Tu herramienta de escritura):**
    *   Es donde escribimos las instrucciones (el código).
    *   *Recomendado:* **Visual Studio Code** (Gratis y muy popular).
    *   *Alternativas:* Sublime Text, Notepad++ o incluso el Bloc de Notas (aunque es más difícil).

2.  **Un Navegador Web (Tu herramienta de visualización):**
    *   Es donde ves el resultado final.
    *   *Ejemplos:* Google Chrome, Microsoft Edge, Firefox, Safari.
    *   *Uso:* Simplemente arrastras el archivo `index.html` a tu navegador para verlo.

## Estructura del Proyecto (¿De qué está hecha?)

La web se compone de tres archivos fundamentales, como los ingredientes de una receta:

*   **`index.html` (La Estructura - El Esqueleto):**
    *   Contiene todo el texto, las imágenes y la organización de la página.
    *   Es lo que le dice al navegador "Aquí va un título", "Aquí va un botón".

*   **`styles.css` (El Diseño - La Ropa):**
    *   Define los colores, fuentes, tamaños y la posición de las cosas.
    *   Aquí es donde pusimos los tonos azules y verdes para dar serenidad.

*   **`script.js` (La Funcionalidad - El Cerebro):**
    *   Maneja las acciones interactivas.
    *   Por ejemplo: que el menú se abra en el celular o que el botón de registro muestre un mensaje.

## ¿Cómo continuar?

1.  Descarga la carpeta del proyecto.
2.  Abre los archivos con tu **Editor de Código** para cambiar textos o colores.
3.  Abre el archivo `index.html` en tu **Navegador** para ver tus cambios.
